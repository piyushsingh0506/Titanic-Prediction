# 🚢 Titanic Survival Prediction

A Machine Learning project that predicts whether a passenger would **survive or not survive** the Titanic disaster based on passenger information such as **Passenger Class, Sex, Age, and Fare**.

## 📌 Project Overview

The **Titanic Survival Prediction** project is a binary classification machine learning application.

The model learns patterns from historical Titanic passenger data and predicts:

* `1` → Survived
* `0` → Did Not Survive

This project demonstrates a complete basic Machine Learning workflow:

**Data → Preprocessing → Model Training → Evaluation → Prediction → API**

---

## 🎯 Objective

The main objective of this project is to build a machine learning model that can predict the survival probability of a Titanic passenger using important passenger features.
